# Llamadas al sistema
- kernel o sistemas operativos son aquellos que ocupan las llamadas al sistema
- Se supone que un proceso no debe acceder al jernel. No debe acceder ni a la memoria del kernel o a sus funciones de manera directa
- Las razones para ello es que:
    - Puede alterar a otros procesos que se estén ejecutando
    - Puede causar daño físico a los dispositivos
